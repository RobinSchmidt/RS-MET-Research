PDE Explorer

Maybe try to write (or vibe code) a little interactive program (maybe in JS or Python as Jupyter
notebook) for exploring linear PDEs with constant coefficients of the general form:

  a_0 + a_1 u_t + a_2 u_tt + ... = b_0 + b_1 u_x + b_2 u_xx + ...

where the user has sliders to dial in the coefficients a_i, b_i and a plot shows the solutions and
updates interactively when the user moves the sliders. It would also need some way to set up intial
and boundary conditions. Maybe it could also make sense to allow for complex coefficients (like in
the Schroedinger equation). If we allow complex coeffs, we could give the user sliders for real and
imaginary parts or maybe use some sort of xy-pad - although I think, that would be harder to use 
because it would be too easy to dial in a nonzero imaginary part unintentionally - so maybe separate
1D sliders are the better choice. Or maybe an xy-pad with a horizontal slider below and vertical to
the right. The constant coeffs a_0 and b_0 could actually be merged into one single coeff but for 
symmetry reasons, I have wrote it down like given. Maybe we could instead replace a_0, b_0 by some 
sort of driving function. Maybe we could use:

  a_1 u_t + a_2 u_tt + ... + b_1 u_x + b_2 u_xx + ... + f(x,t) = 0

or

  a_1 u_t + a_2 u_tt + ... + b_1 u_x + b_2 u_xx + ... = f(x,t)

instead. We could set f(x,t) to a constant, too. The plot should be some sort of 2D plot. Maybe with
x going from left to right and t going from front to back such that the front represents the state 
"now" and the back represents the initial condition. Maybe there could also be a time slider that 
sets up, what "now" means such that the plot always shows the entire history up to now in a sort of
waterfall plot.

Transparent Oversampling (partially done)

Use an interactive chat with a mathematically and algorithmically well versed AI model to figure out
hwo to implement the transparent oversampling idea explained here:

 RS-MET-Research/Notes/DSP/TransparentOversampling.txt
 
In the experiments here in this repo, I have already implementations for the simplemost cases. The 
goal is to generalize this idea to higher order (and higher quality) up- and downsampling filters. 
It will probably have to be formulated as a constrained optimization problem. But that's something 
the AI should figure out.


Prompt:

I write audio signal processing algorithms for musical purposes. In this context, it is often necessary to use oversampling, i.e. to first upsample an incoming signal to a higher sample rate, then do the actual processing at that higher rate, then downsample it to the original sample rate again. Both, up- and downsampling steps involve lowpass filtering the signal. In the case of upsampling, the lowpass is called anti-imaging lowpass, in the case of downsampling, it's called anti-aliasing lowpass. What I want to create is a pair of FIR upsampling and downsampling filter kernels (let's denote them by u[n] and d[n] respectively), such that an upsampling-downsampling roundtrip is an exact identity operations (up to floating point roundoff errors). For concreteness, let's assume I want to implement a waveshaping distortion effect. So, the processing would be:

  input -> upsample -> waveshaper -> downsample -> output

The goal is that my oversampled distortion algorithm is completely transparent as long as the waveshaper that sits in between the upsampler and the downsampler is itself an identity function (i.e. does nothing). Is there any known literature for this particluar type of filter design problem?
